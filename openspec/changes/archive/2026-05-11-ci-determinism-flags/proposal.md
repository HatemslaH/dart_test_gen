## Why

В README пункт TODO #9 («CI и детерминизм») остался открытым: нет ни документации того, как снимок зависит от SDK/платформы (float-арифметика, runtime-имена исключений, локали), ни инструмента, который бы в CI ловил «забыли перегенерировать тесты после изменения кода». Кроме того, в коде `lib/` накопилось 112 строк с русскоязычными комментариями (8 файлов из 10), что мешает контрибьюторам и LLM-инструментам и расходится с практикой «комментарии — на английском». Обе задачи укладываются в одну тематическую правку: «сделать дистрибутив пригодным для интеграции в CI и для внешних читателей».

## What Changes

- Добавить флаг **`--dry-run`** в `dart_test_gen`: пайплайн исполняется до конца, но финальная запись `test/…_test.dart` пропускается. В stdout выводится список путей, которые **были бы** записаны (по одному в строке). С `-v` дополнительно печатается полный контент в stderr. Подходит для smoke-проверок без модификации рабочего дерева.
- Добавить флаг **`--check`**: пайплайн исполняется как обычно, но вместо записи сравнивает сгенерированный контент с уже существующим тест-файлом. Если файл отсутствует или содержимое отличается (после нормализации волатильной строки `// Сгенерировано: <timestamp>`) — печатает diff-summary в stderr (путь + первые расходящиеся строки) и завершает процесс с кодом `1`. Если всё совпадает — exit `0`. Подходит как CI-стейдж «тесты актуальны и закоммичены».
- `--dry-run` и `--check` взаимоисключающие; одновременная подача — ошибка валидации (`exit 64`).
- Раздел README **«CI и детерминизм»**: документировать, что снимки зависят от Dart SDK (`Platform.version`) и платформы (имена приватных рантайм-типов, IEEE-754 точность); рекомендация — пиннить версию SDK в CI и пользоваться `use_close_for_double` для `double`-ассертов. Привести пример использования `--check` в GitHub Actions.
- **Перевод комментариев `//` / `///` в `lib/` с русского на английский.** Затрагивает 8 файлов: `cli_log.dart`, `cli_progress.dart`, `gen_config.dart`, `generate_pipeline.dart`, `resolved_dependencies.dart`, `snapshot.dart`, `source_parser.dart`, `test_generator.dart`. Пользовательские строки (CLI-сообщения, лог-лейблы) **не трогаем** — это отдельная задача (i18n) и менять формат стабильных сообщений в этой правке рискованно.

- Обновления существующих тестов: `test/cli_smoke_test.dart` (расширить список ожидаемых флагов в `--help`); golden-style проверки баннера, если найдутся.
- Регенерация: `example/lib/usecases/.../*_test.dart` перегенерируется один раз для смены баннера `// Сгенерировано:` → `// Generated:`.
- Перевод комментариев: 8 файлов в `lib/`. Никаких изменений в строках/идентификаторах/API.
- README: новая секция «CI и детерминизм», обновлённый список флагов, TODO #9 → `[x]`.
- Совместимость: `--check` сознательно ломает CI, если забыли перегенерировать (это и есть его смысл). `stripGeneratedTimestamp` принимает оба баннера — старые закоммиченные файлы не дают ложно-положительных diff'ов после смены префикса.
