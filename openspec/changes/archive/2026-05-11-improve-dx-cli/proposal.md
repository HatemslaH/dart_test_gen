## Why

TODO #8 в `README.md` фиксирует два DX-болевых места: (1) точкой входа служит `bin/generate.dart`, а не одноимённый с пакетом `dart_test_gen`-бинарь, поэтому в `pubspec.yaml` нет секции `executables` и команда не доступна как `dart pub global run dart_test_gen ...` / через `dart run dart_test_gen:dart_test_gen`; (2) когда временный раннер-снимок не компилируется или его вывод не совпадает с ожидаемым форматом, ошибка пробрасывается голым stacktrace из изолята — пользователю не видно, какой файл/класс/метод дал сбой и какие действия предпринять.

## What Changes

- **Единый бинарь `dart_test_gen`.** Переименовать содержательную точку входа в `bin/dart_test_gen.dart` (сейчас там заглушка `print('Hello world!')`), сохранить `bin/generate.dart` как тонкий deprecation-shim, который печатает в stderr предупреждение и делегирует в новый бинарь. Добавить секцию `executables: { dart_test_gen: dart_test_gen }` в `pubspec.yaml`, чтобы команда работала через `dart pub global activate` / `dart run dart_test_gen`.
- **Сообщения об ошибках раннера снимка.** Когда раннер не компилируется или его stdout не соответствует ожидаемому формату (`isolateResultPrefix`/JSON снимка), вместо голого stacktrace выводить структурированную диагностику: путь к lib-файлу, имя класса, имя метода (если известно), путь к временному раннеру, первые строки stderr `dart` и подсказку («перезапустите с `-v` для подробного лога», «проверьте, что метод не зависит от внешнего IO», «сообщите о баге со ссылкой на временный файл»). Сохранять артефакт временного раннера при ошибке (или по флагу `--keep-runner`) и печатать его абсолютный путь.
- **`--help` и `--version`.** Добавить стандартные флаги верхнего уровня. `--help` печатает список опций (соответствует README), `--version` читает версию из `pubspec.yaml`.
- **BREAKING (мягкий)**: вызовы `dart run bin/generate.dart …` продолжают работать через shim, но при каждом запуске печатают в stderr `[deprecated] use 'dart run dart_test_gen' instead`.

## Capabilities

### New Capabilities
- `cli-entrypoint`: единая точка входа `dart_test_gen`, регистрация в `pubspec.yaml`, `--help` / `--version`, политика обратной совместимости со старым `generate.dart`.
- `snapshot-runner-diagnostics`: формат сообщений об ошибках при сбое раннер-снимка (контекст файла/класса/метода, путь к артефакту, действенные подсказки) и флаг сохранения временного раннера.
